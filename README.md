# Laboratório Virtual de Física

## Sobre o projeto

O **Laboratório Virtual de Física** é um projeto acadêmico desenvolvido com o objetivo de criar um ambiente interativo para o estudo de conceitos de Física, com foco em **Cinemática e Dinâmica**.

A proposta é permitir que os usuários explorem fenômenos físicos por meio de simulações, alterando parâmetros e observando seus efeitos. Dessa forma, o projeto busca complementar o aprendizado teórico com experimentação virtual.

## Objetivos

- Desenvolver um laboratório virtual com simulações de fenômenos físicos.
- Facilitar a compreensão de conceitos de Cinemática e Dinâmica.
- Permitir a alteração de parâmetros físicos e a visualização dos resultados.
- Aplicar conhecimentos de desenvolvimento web e programação em JavaScript.
- Desenvolver habilidades de trabalho em equipe e organização de código.

## Tecnologias utilizadas

- **HTML:** estrutura das páginas e dos elementos da interface.
- **CSS:** estilização e organização visual.
- **JavaScript:** lógica das simulações e interatividade.
- **Canvas API:** desenho e animação dos elementos gráficos das simulações.

## Funcionalidades planejadas

### Cinemática

- Movimento Retilíneo Uniforme
- Movimento Retilíneo Uniformemente Variado
- Queda livre

### Dinâmica

- Segunda Lei de Newton
- Força resultante
- Trabalho de uma força

As funcionalidades poderão ser ajustadas durante o desenvolvimento do projeto.
